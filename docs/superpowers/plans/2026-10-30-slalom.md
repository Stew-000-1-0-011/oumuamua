# Slalom Trajectory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 添付の実形状で、入口から出口と出口から入口の軌道を再生成・検証する。

**Architecture:** 原形状を別YAMLに保存し、経路定義に+pi/2変換を明示する。既存生成器の幾何検査を補強し、両方向と端点の下形状が40 mm余裕を満たす場合だけCSVを出力する。

**Tech Stack:** Python 3、PyYAML、unittest、matplotlib、既存C++ CSV読込/軌道補間。

**Spec:** `docs/superpowers/specs/2026-10-30-slalom-design.md`

## Global Constraints

- 添付→base_link: `(x_base, y_base) = (-y_attachment, x_attachment)`。
- 往復は昇降上、入口・出口は昇降下も検証。必要最小間隔0.04 m。
- 入口 `[-2.05, 0.668, pi]`、出口 `[1.25, 1.273, pi]`。復路は同じ姿勢の逆順。
- 内壁padding 0.0025 m、外周bounds padding 0.005 mをこの経路の検証に適用。
- フィールド共有値、他経路、TF、把持位置、速度・昇降制御は変更しない。

## Review Focus

- 多角形内部の障害物・辺交差を見落とさない（Task 1）。
- 位置とyawが補間される区間の衝突を検出する（Task 1）。
- 外部YAMLが文字列形式のfootprintでも正しく変換する（Task 1）。
- 下状態の端点違反や生成失敗で既存CSVを上書きしない（Task 1/2）。
- CSV丸め後も余裕・端点・復路姿勢が成立する（Task 2）。
